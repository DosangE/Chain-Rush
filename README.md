# Chain-Rush

그래플링을 핵심 재미로 삼은 Unity 기반 2D 러닝 액션 게임. 기획부터 개발까지 1인으로 진행 (2025.09 ~ 2026.02)


## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 러닝 액션 |
| 기간 | 2025.09.17 ~ 2026.02.24 |
| 인원 | 1인 (기획 · 프로그래밍 전반) |
| 사용 기술 | Unity, C# |

## 핵심 구현

**그래플링 시스템**
- `Physics2D.Raycast`로 그래플링이 가능한 대상을 탐색
- `DistanceJoint2D`로 캐릭터를 목표 지점까지 이동시키는 이동 시스템 구현
- 두 API를 이어 붙이는 것만으로는 원하는 움직임이 나오지 않아, Rigidbody의 질량과 힘, Joint의 거리 제약, Anchor 위치가 서로 어떻게 영향을 주는지 확인하며 조작감이 나올 때까지 값을 조정했습니다.

**게임 진행**
- 장애물 생성 및 게임 진행 로직 구현

**구조 개선**
- 그래플링과 맞물리는 기능이 늘어나면서 연결 판정 · 물리 제어 · 상태 관리가 한 스크립트에 몰려 결합도가 높아졌습니다.
- 역할별로 클래스를 분리해, 이후 기능을 추가하거나 수정할 때 다른 시스템에 미치는 영향을 줄였습니다.

**프로토타입 아트**
- 초기 개발 속도를 높이기 위해 OpenAI Image Generation으로 UI · 아이콘 등 프로토타입 리소스를 직접 제작했습니다.
